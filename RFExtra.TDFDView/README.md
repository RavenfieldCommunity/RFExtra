# RFExtra.TDFDView

A plugin to provide friendly orthographic vision in spectator mode.

# Installation 
- Install BepInEx
- Install [BepInEx.ConfigurationManager](https://github.com/BepInEx/BepInEx.ConfigurationManager) (FOLLOWING plugin zip archive includes it)
- Download [the plugin](https://github.com/RavenfieldCommunity/RFExtra/releases/tag/SinglePackages) and put it to folder `BepInEx\plugins\`

# Usage
Launch the game, then you can press `F1`(default) or `Left alt`+`S` to edit the config and invoke other features.

When you are in spectator team or spectator mode by press "F8" in game, Press "Left ctrl" +"H" to enable 2.5D vision

Press "Q/E" to adjust camera depth(like slice capture lol, adjusting to a suitable depth to get a slower camera rotation)

Press "W/A/S/D" to move

Scroll mouse middle button to adjust camera moving speed

Press "Left ctrl" + scroll mouse middle button to zoom 

Press "Mouse middle button" to lock or smooth camera movement(mainly for fixing original camera bug but not for features)

Press "L" to switch camera target mode when you target a bot by left mouse button click(right click to cancel targeting)
