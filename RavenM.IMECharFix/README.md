# RavenM.IMECharFix

A plugin to fix RavenM([CHN Edition](https://github.com/RavenfieldCommunity/RavenM/releases/tag/test))'s potential crash when typing non-english message.

# Installation 
- Install BepInEx
- Install RavenM
- Install [BepInEx.ConfigurationManager](https://github.com/BepInEx/BepInEx.ConfigurationManager)
- Download [the plugin](https://github.com/RavenfieldCommunity/RFExtra/releases/tag/SinglePackages) and put it to folder `BepInEx\plugins\`

# Usage
Launch the game, then you can press `F1`(default) or `Left alt`+`S` to edit the config and invoke other features.
